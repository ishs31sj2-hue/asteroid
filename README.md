# Asteroid Shape Reconstruction from Lightcurves

This project contains a small, fully self-contained reference implementation of a Kaasalainen-style convex lightcurve inversion algorithm.  
Given time series photometry and the associated observing/illumination geometries, the tool iteratively recovers a convex 3D shape model of an asteroid and exports it as a triangular mesh.

The implementation follows the high level strategy of the Kaasalainen & Torppa (2001) algorithm:

1. Represent the asteroid as a convex polyhedron whose radial distance is defined along a fixed set of directions (derived from a subdivided icosahedron).
2. Evaluate the disk-integrated brightness by summing the contributions of all illuminated and visible facets using a combined Lambert + Lommel-Seeliger scattering law.
3. Optimise the facet radii by minimising the squared error between observed and modelled lightcurves, with a smoothness prior that penalises sharp radial jumps between neighbouring directions.

Although the numerical scheme is intentionally compact (finite-difference gradients and gradient-descent updates), it preserves the essential components of the Kaasalainen approach: convex shape support functions, physically-motivated photometry, and simultaneous inversion of all observation geometries.

## Installation

The repository has no external dependencies beyond NumPy. The project is defined as a standard Python package, so you can install it in editable mode while experimenting:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Input data

The solver expects a CSV file with the following header:

```
time,brightness,sun_x,sun_y,sun_z,observer_x,observer_y,observer_z
```

Each row stores a single observation. The Sun and observer vectors must be expressed in the asteroid-centric frame and should be normalised. Brightness values can be either relative or absolute units; the optimisation works with whatever scale is provided.

An example synthetic dataset can be found in [`examples/sample_lightcurve.csv`](examples/sample_lightcurve.csv). It was generated by simulating photometry of a triaxial ellipsoid over many aspect/phase angles and adding a small amount of white noise.

## Usage

Once installed (or when running via `python -m`), the reconstruction command can be invoked as follows:

```bash
python -m asteroid_reconstruction.cli \
    examples/sample_lightcurve.csv output.obj \
    --iterations 60 --subdivisions 1 --regularisation 0.02 --step-size 0.08
```

Key options:

- `--iterations`: Number of gradient-descent iterations.
- `--subdivisions`: Icosahedron subdivision depth. Higher values increase resolution but also the number of parameters.
- `--regularisation`: Smoothness weight applied to neighbouring radial differences.
- `--step-size`: Gradient-descent step size.
- `--report`: When provided, the solver writes an iteration-by-iteration loss history to the given path.

The solver prints the final loss and writes the optimised mesh to the output OBJ file. The output can be inspected with any 3D viewer such as MeshLab or Blender.

## Generating synthetic data

To experiment with different lightcurves you can run the helper script:

```bash
python examples/generate_sample.py --output new_lightcurve.csv --samples 200
```

The script simulates brightness measurements of a known ellipsoidal shape using the same photometric model as the inversion routine.

## Limitations

- The implementation models convex shapes only. Non-convex features or concavities cannot be recovered.
- Optimisation relies on finite-difference gradients; for very large datasets you may prefer to replace them with analytical derivatives for speed.
- No spin state optimisation is performed. The observing geometry vectors must already be expressed in the asteroid's body frame for each timestamp.

Despite these simplifications, the code provides a practical starting point for Kaasalainen-style inversion experiments and can be extended with period search, multi-band photometry, or sparse photometric datasets.
